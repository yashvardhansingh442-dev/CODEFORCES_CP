# 4A. Watermelon

**Platform:** Codeforces | **Difficulty:** ~800 | **Tags:** brute force, math

## Problem

Two friends buy a watermelon that weighs `w` kilos. They want to split it
into two parts such that each part weighs an **even** number of kilos.
The parts don't need to be equal, but each must have a positive weight.

Determine whether this is possible.

## Input

A single integer `w` (1 ≤ w ≤ 100), the weight of the watermelon.

## Output

Print `YES` if the watermelon can be split as described, otherwise `NO`.

## Example

Input:
8

Output:
YES

(8 = 2 + 6, and both parts are even.)
